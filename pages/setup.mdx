## **Download**
To use the library you'll need to get it as a model in the [Roblox Store](https://create.roblox.com/store/asset/134169661187830/VFXLibrary)
as a package that you can always update to the latest published version.

## **Studio Setup**

After installing the package, you'll need to initialize it once on the client. After that you are good to use the effects of the library wherever.

```lua filename="Initializing the library" {} copy
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local vfxLibrary = require(ReplicatedStorage.Packages.VFXLibrary)

vfxLibrary.Init()
```

There are a set of settings for each effect that can be adjusted to your liking, it's highly
recommended to visit each effect's specific settings and disable unwanted effects from Initializing
for maximum optimization.  
If not specified the module uses a set of default settings that are mid to lower on the preformence
scale:

```lua filename="Default library settings" {} copy
local defaultLibSettings = {
	Rocks = {Size = 500},
	Lightning = {Size = 1000},
}
```

**Warning: not all effects were developed to be used on the server, if an effect isn't working as intended ensure it is being initlizied in the correct enviornment.**
